# AeroEquity Partners

A responsive multi-page Next.js website concept for an aviation-focused airline equity research and investment venture.

## Run locally
1. Install Node.js (LTS).
2. Extract this project.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Before publishing
- Replace all placeholder contact details and company information.
- Have a qualified lawyer review the Privacy Notice, Terms, Risk Disclosure and other legal copy for the jurisdictions where you operate.
- Do not describe the business as licensed, regulated, authorised, or managing client money unless that is legally accurate and independently verified.
- The site is an informational concept, not a brokerage, investment adviser, fund, or securities offering.
- Connect a real, secure form backend before collecting visitor information. The current contact form opens the visitor's email application.
- Review image licensing and replace stock image URLs with properly licensed assets if required.
- Add analytics/cookie tooling only after selecting vendors and updating the privacy notice accordingly.
